# Тестовое задание для компании JeLeApp (Full-stack разработчик)

Full-stack приложение, состоящее из бэкенда на **Laravel** и фронтенда на **Vue.js**, разработанное в рамках тестового задания.

## 📁 Структура проекта

```text
.
├── client/      # Фронтенд-часть (Vue 3, Vite, Vue Router)
├── codestyle/   # Настройки линтинга и форматирования кода
└── server/      # Бэкенд-часть (Laravel 11, Laravel Sanctum, SQLite)
```

---

## 🚀 Реализованный функционал

### 1. Бэкенд (`server/`)

- **`POST /api/registration`**: Регистрация нового пользователя.
  - Валидация полей: `email` (уникальный, корректный формат), `password` (минимум 8 символов), `gender` (строка).
  - Пароль безопасно хешируется с помощью `Hash::make`.
  - После успешной регистрации автоматически генерируется и возвращается API-токен авторизации (**Laravel Sanctum**).
- **`GET /api/profile`**: Получение данных профиля авторизованного пользователя. Роут защищен middleware `auth:sanctum`.

### 2. Фронтенд (`client/`)

- Форма регистрации со следующими полями:
  - **Email**: HTML5 валидация и проверка формата.
  - **Пароль**: Скрыт по умолчанию, минимальная длина — 8 символов. Реализована интерактивная кнопка «Показать/Скрыть».
  - **Пол**: Выпадающий список (Мужской/Женский).
- Логика отправки:
  - Запрос отправляется на бэкенд через `fetch`.
  - Результат ответа и сам запрос логируются в консоль браузера (согласно ТЗ).
  - При успешном ответе токен сохраняется в `localStorage`, и выполняется редирект на страницу профиля.
- Страница профиля:
  - При монтировании отправляет GET-запрос на `/api/profile` с Bearer-токеном в заголовках.
  - Отображает полученную модель пользователя в текстовом виде (`<pre>`).

## 🛠 Локальное развертывание

### Шаг 1. Бэкенд (Laravel)

1. Перейдите в папку сервера:
   ```bash
   cd server
   ```
2. Установите зависимости:
   ```bash
   composer install
   ```
3. Скопируйте файл окружения и настройте SQLite:
   ```bash
   cp .env.example .env
   ```
   В файле `.env` установите:
   ```ini
   DB_CONNECTION=sqlite
   ```
4. Выполните миграции (Laravel автоматически предложит создать файл `database.sqlite`):
   ```bash
   php artisan migrate:fresh
   ```
5. Запустите локальный сервер:
   ```bash
   php artisan serve
   ```
   Бэкенд станет доступен по адресу `http://127.0.0.1:8000`.

### Шаг 2. Фронтенд (Vue 3)

1. Перейдите в папку клиента:
   ```bash
   cd client
   ```
2. Установите npm-зависимости:
   ```bash
   npm install
   ```
3. Запустите сервер для разработки:
   ```bash
   npm run dev
   ```
   Фронтенд станет доступен по адресу `http://localhost:5173`.
